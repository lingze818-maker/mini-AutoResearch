# 走步折对照（2026-11-21）

这不是可实盘策略，也不是无偏发现。

`pass` 只表示没有触发写死淘汰线：样本外最大回撤超过 25%，或任一侧日均换手超过 20%。等于 25% 或等于 20% 都不淘汰。样本内回撤超过 25% 本身不淘汰。这六次里没有一行的 `rule_id` 是 `oos_drawdown`。记成 `pass` 的行，官方 `rule_id` 都是 `aligned_pass`：样本内外收益同号，而且上面两条线都没超过。两边都是负收益也算同号，所以仍可以是 `pass`。它不表示规则能赚钱。

折 A、B、C 的样本外是预注册走步窗口，`kind` 为 `pre_registered_walk_forward`，不是此前披露的 2024–2026 holdout（`already_inspected_historical_holdout`）。这些日期曾属于更早的样本内，仍不是未触碰的验证集。不能按这些样本外结果继续搜索，也不能把不同窗口的指标混进一张「谁更好」的排行。重复出现的源码哈希不是新的独立发现。

冻结的 20/60 双均线基线已经在 2024–2026 上判定过。官方记录没有声称它在 2021、2022、2023 这些折窗口上做过样本外判定。走步折里出现同一类规则，只说明规则家族相似，不是把基线结论搬过来，也不能把基线数字和下面任一折的数字混比。
